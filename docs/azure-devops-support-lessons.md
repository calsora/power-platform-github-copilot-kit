# Azure DevOps Support Lessons

This file contains human-reviewed, reusable lessons for first-line support. The support agent may suggest entries in chat, but a maintainer must review and add them here.

Before adding a lesson, remove names, customer or tenant details, environment identifiers, URLs, work-item IDs, secrets, and any information that could identify an incident. Prefer general symptoms, diagnostic evidence, root causes, safe resolutions, and verification steps. Do not copy incident transcripts or logs verbatim.

## Lesson format

### Short descriptive title

- **Symptoms:** Generalized user-visible symptoms.
- **Evidence:** Safe, reusable evidence that distinguishes the issue.
- **Likely cause:** The confirmed cause, not an unverified hypothesis.
- **Resolution:** Approved resolution steps.
- **Verification:** How to confirm recovery and avoid recurrence.
