# Provisional Azure DevOps Support Lessons

Add entries here manually after reviewing a sanitized lesson draft from the first-line support agent and confirming that its resolution worked. These entries are unverified hints, not authoritative guidance. The agent must validate them against current evidence before relying on them. Review, correct, or remove entries before promoting any into human-reviewed guidance.

Entries must be generalized and sanitized. Never include organization, project, customer, user, or environment identifiers; URLs; work-item IDs; credentials; secrets; private data; or verbatim incident descriptions, logs, wiki text, or stack traces.

## Lesson format

### Short generalized title

- **Symptoms:** Generic user-visible symptom.
- **Confirming evidence:** Reusable evidence that establishes the pattern.
- **Confirmed cause:** Cause confirmed by the user or verified resolution.
- **Resolution pattern:** General corrective action; avoid environment-specific commands.
- **Verification:** General way to confirm recovery.
